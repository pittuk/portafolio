Una observación importante
El mayor activo de tu web no es que sabes usar WordPress, Elementor o WooCommerce. Eso muchos lo ofrecen.
Lo que te diferencia es que combinas diseño gráfico, UX, desarrollo web, administración de servidores, SEO técnico e integraciones, algo que se aprecia en la variedad y complejidad de tu portafolio. 
Mi recomendación sería dejar de venderte como "desarrollador WordPress" y posicionarte como alguien que construye sitios web orientados a generar negocio, usando WordPress como herramienta y no como el producto principal. Esa diferencia cambia el tipo de cliente que atraes y te permite competir más por valor que por precio.
